## Product Summary

FORGE is a pocket AI HYROX coach and race prep planner. The application helps athletes prepare for HYROX by generating long-term training blocks, building weekly plans, adapting workouts to the equipment available in the current gym, deriving running paces and race splits from target time and PRs, tracking training logs/PRs, and using readiness feedback to adjust training load.

The core product is no longer only a seven-day plan demo. It now has the structure of a Web MVP+ training product: Home, Train, Coach, Race, Metrics, and Profile, backed by deterministic coaching logic and PostgreSQL-ready data models.

## Current Completion State

Web MVP+ implementation is complete enough for GitHub/product review and ready for deployment wiring.

Completed:

- Public `/demo` mode for visitors without account creation, database setup, or LLM API key.
- AI-assisted 7-day HYROX microcycle generation.
- Deterministic 4-8 week long-term planning with base/build/peak/taper phases.
- Readiness-aware week generation from a long-term plan.
- Train Hub at `/train` with current block, HYROX workout template library, filters, scheduling, and manual builder.
- Coach workspace at `/coach` with long-term plan, current-week plan, and single-workout generation.
- Race Prep at `/race` with target finish time, run splits, station splits, ROXZONE, manual adjustment, and saved race plans.
- Metrics dashboard at `/metrics` with completion, streak, weekly load, readiness trend, pain notes, and station weakness.
- Built-in HYROX workout template library with 30+ templates across engine, strength, compromised running, race simulation, recovery, no-equipment, and hotel-gym use cases.
- PostgreSQL Prisma schema with:
  - `TrainingPlan`
  - `TrainingWeek`
  - `ScheduledWorkout`
  - `WorkoutTemplate`
  - `RacePlan`
  - `ReadinessSnapshot`
  - `CoachGeneration`
- Local fallback microcycle when the LLM/API fails or generated output fails validation.
- Coach Core guardrails:
  - exactly 7 days
  - exactly one rest day
  - at least two running sessions
  - no empty non-rest days
  - no unavailable equipment in final validated plan
- Equipment-aware local substitutions for sled, SkiErg, wall ball, sandbag, rower, bike, cable, dumbbell, kettlebell, and related station work.
- "Today's Gym" equipment toggles inside workout detail.
- PR-aware running prescription engine:
  - easy
  - race
  - threshold
  - interval
- Pacing engine connected to PRs and target finish time.
- Readiness feedback loop from recent completed logs, RPE, pain notes, and red-flag symptoms.
- Red-flag safety detection for notes like chest tightness, dizziness, numbness, sharp pain, swelling, etc.
- Coach Notes on generated training days.
- Plan Adjustments explaining why FORGE reduced volume, used fallback planning, applied taper logic, or respected missing equipment.
- Database-first sync for profile, equipment, microcycle, edited WODs, substitutions, daily logs, RPE, and station PRs.
- Explicit auth checks on LLM/API routes with JSON 401 responses.
- Next 16 `proxy.ts` auth behavior adjusted for API JSON responses and demo access.
- Bilingual English/Chinese UI cleanup.
- README reorganized as English-first with Chinese in a collapsible section.
- Screenshot assets refreshed for GitHub README.
- CI workflow for core tests, API smoke tests, type checking, and production build.
- Initial Prisma migration committed.
- PostgreSQL migration committed.
- Deployment notes added.
